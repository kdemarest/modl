# ModlScript

ModlScript is a language for creating 3D models and texturing them. Build complex 3D geometry and apply detailed textures using an intuitive scripting interface.

## Features

- Declarative 3D model creation
- Texture mapping and material definitions
- Easy-to-learn scripting syntax
- Flexible and extensible
